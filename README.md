# Kamaina - Global Game Jam 2026

A 2D mobile platformer with 3D props, built with Unity during Global Game Jam 2026.

**[Play / Download](https://soyelchecho.github.io/GlobalGameJam2026/)** | **[Global Game Jam Page](https://globalgamejam.org/games/2026/kamaina-7)**

## About

Kamaina is a vertical climbing platformer where you race against rising lava, collect ancient masks with unique powers, and navigate treacherous volcanic terrain. Built for mobile (Android) with touch controls.
